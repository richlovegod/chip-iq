7729 仲恩生醫 籌碼與市值監測 · 版本紀錄

給接手維護的人看的：每一版改了什麼、為什麼改。
發新版的固定動作（三處要一起改，少一處就對不上）：
① 在 data/versions.json 最前面加一筆（version、dateDisplay、title、changes）
② 改 index.html 頁首與頁尾的版本號
③ commit 訊息寫清楚「為什麼」——這一頁是給人看的摘要，git log 才是完整脈絡
版號規則：介面或資料源有新東西 → 第二位進位（v0.4 → v0.5）；只修 bug 或守門員 → 第三位進位（v0.4 → v0.4.1）。

維運要知道的事
排程 .github/workflows/daily.yml，每個交易日台北 18:17 與 20:47 兩個時段（GitHub 免費排程實測中位晚 2 小時、最近固定晚 4 小時，兩個時段互為備援），也可手動觸發。頁首「最後更新」顯示實際跑的時間。
四道守門員 verify_broker.py（分點對 2026-07-21 黃金樣本）、verify_partners.py（夥伴 12 項＋突變測試）、verify_site.py（全站形狀與日期）——任一失敗就不 commit，網站停在昨天的好資料。
失敗了怎麼看 GitHub Actions 頁面點進失敗的 run，看紅色那步的最後 20 行；守門員的訊息會直接說是哪一項、什麼值對不上。
不要在台北 13:30–14:30 手動觸發：TWSE 那段時間停用全市場查詢（自稱到 13:45，實測 runner 在 14:05 仍被擋），會失敗，訊息會直接說明。剛收盤時各端點出檔時間不一，手動觸發也容易拿到日期不一致的快照，讓晚上的排程跑最乾淨。
